Tento web nepoužívá cookies, neměří návštěvnost a nemá žádné formuláře.

Správce

Správcem osobních údajů je Emineo, z. s., IČO 29961734, se sídlem Vítězné náměstí 1145/8, 160 00 Praha 6. S dotazy k ochraně údajů pište na info@emineo.cz.

Návštěva webu

Stránky jsou obyčejné soubory bez skriptů. Do prohlížeče nic neukládají a nenačítají obsah z jiných webů.

Web běží na službě GitHub Pages společnosti GitHub, Inc. se sídlem ve Spojených státech. GitHub při načtení stránky zaznamenává technické údaje včetně IP adresy, aby mohl službu provozovat a chránit ji před zneužitím. K těmto záznamům nemáme přístup. Podrobnosti najdete v prohlášení GitHubu o ochraně soukromí.

Když nám napíšete

Vaši e-mailovou adresu a obsah zprávy použijeme k tomu, abychom vám odpověděli. Právním základem je náš oprávněný zájem vyřídit vaši zprávu.

Zprávy uchováváme jen po nezbytnou dobu a nikomu je nepředáváme, kromě poskytovatelů e-mailových služeb, kteří je doručují.

Můžete se zeptat, jaké údaje o vás máme, a požádat o jejich opravu nebo výmaz. Můžete také vznést námitku proti zpracování nebo požádat o jeho omezení. Stačí napsat na info@emineo.cz.

Stížnost můžete podat u Úřadu pro ochranu osobních údajů.
